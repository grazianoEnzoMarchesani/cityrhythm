# Istruzioni per gli agenti — CityRhythm

1. **Prima di qualsiasi altra cosa, leggi `second-brain/SECOND_BRAIN.md`** (indice: progetto, regole permanenti, prossimi passi, diario). Poi leggi i file di argomento elencati nella sua sezione "Dove trovare cosa" che toccano il lavoro da fare (`bussola-clima.md`, `audio.md`, `mappa.md`, `persone.md`, `strumenti.md`) e **sempre `decisioni-superate.md` prima di proporre una scelta**. Non riaprire decisioni già prese senza un motivo nuovo.
2. Se servono i prompt musicali, sono in `second-brain/prompts.md`.
3. **A fine sessione, quando l'utente lo chiede**, aggiorna il second brain seguendo `.claude/skills/second-brain/SKILL.md` (in Claude Code: comando `/second-brain`).
4. L'utente scrive in italiano e non ha competenze musicali: spiega le scelte sonore con parole semplici.
